bazar-dor is a web-based application designed to help people in Bangladesh check and compare the prices of everyday market products. It aims to make shopping easier, improve price transparency, and help consumers make informed purchasing decisions.

->Technologies Used

Frontend: Next.js, React.js

Styling: Tailwind CSS

Language: TypeScript / JavaScript

Authentication : Better-Auth



->Key Features

1.Product Price Tracking — View the latest available prices of everyday essential products.

2.Search Products — Quickly find products by name or category.

3.Price Comparison — Compare product prices to identify affordable options.

4.User Authentication — Securely sign up and log in to access your account.

5.Account Management — Update your profile information and log out securely.
